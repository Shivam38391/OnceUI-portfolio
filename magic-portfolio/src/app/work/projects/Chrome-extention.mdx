## Overview: Writing and Enhancing on Your Own Terms

Tired of navigating subscription paywalls and sluggish, memory-heavy browser extensions that lag input fields? Drafty is a specialized **open-source developer tool** designed to bring lightning-fast clarity and prompt optimization directly to your browser's native text areas.

Its entire architecture is built around creating a **direct-connect pipeline** that successfully bypasses centralized service charges and bloated middleware. This platform empowers users to manage their entire text-polishing and prompt-engineering loop locally, ensuring complete privacy, zero layout disruption, and instant AI text manipulation on their own terms.

## Key Features for Users: Deterministic and Clean Outputs

For users looking to refine written content or boost their engineering prompts, Drafty offers powerful tools designed for maximum speed and structural purity:

- **Raw Text Delivery:** By leveraging highly optimized API configurations, the tool returns strictly polished prose ready for immediate consumption. It explicitly avoids conversational fluff, summaries, or pleasantries.
- **Full Prompt Autonomy:** Users can choose between a standard grammatical overlay or execute deep prompt expansion, ensuring they get the exact stylistic resolution required for their workflow.
- **No Markdown Filler:** Unlike traditional AI interfaces that dump conversational code blocks into text windows, the background engine automatically sanitizes outputs, stripping out trailing backticks and formatting artifacts.
- **Instant Clipboard Integration:** A built-in utility allows users to easily copy rewritten text strings instantly or inject them directly back into the targeted web field with a single click.

## Enhanced Experience for Developers: Zero-Dependency UI Mechanics

Developers benefit from an open-source codebase focused completely on layout performance, modular typing, and minimal reliance on external packages:

- **Lightweight UI Layer:** Styled entirely in **Tailwind CSS** with crisp **Lucide React** vector icons, the extension bypasses bloated UI libraries, keeping the extension's background memory signature at an absolute minimum.
- **Native Pointer-Based Dragging:** The floating interface features a custom draggable layout constructed using standard **Pointer Events** (`setPointerCapture`). This provides ultra-fluid window tracking across both mouse inputs and touch screens without relying on heavy external runtime binaries.
- **Viewport Containment Math:** Integrated placement logic intercepts the DOM's bounding client rectangles to mathematically position the panel securely within active screen thresholds, completely preventing off-screen overflow.
- **Manifest V3 Async Architecture:** The background worker lifecycle leverages explicit asynchronous message channels (`chrome.runtime.onMessage`), holding network pipelines open systematically until the generative engine securely resolves.

## Outcome: A Transparent, High-Performance Ecosystem

Drafty has successfully established a lightweight digital blueprint for localized AI text processing. By prioritizing **zero-dependency frontend engineering** and **complete text transparency**, the extension ensures that users can refine content efficiently without trading off browser speed.
